The 42 Common Core is an intensive, project-based curriculum with no teachers and no lectures.
Every project is built from a subject, then defended in front of other students through peer evaluation.
It covers low-level programming in C, Unix system calls, processes and threads, networking,
graphics, object-oriented programming in C++ and system administration with Docker.

This repository gathers every project I completed during the Common Core at **42 Lyon**.

## 🛠️ Build

Every project has its own `Makefile`:

```bash
cd <project>
make        # build
make clean  # remove object files
make fclean # remove object files and binary
make re     # rebuild from scratch
```

C projects are compiled with `cc -Wall -Wextra -Werror` and follow the 42 coding standard (the Norm).
C++ projects are compiled with `c++ -Wall -Wextra -Werror -std=c++98`.
